# Rightmove

> Rightmove is the United Kingdom's largest residential property portal, operated by Rightmove Group Limited (Milton Keynes) and listed on the London Stock Exchange as Rightmove plc. Its API posture is publish-in, not read-out: the documented APIs let an estate agent's CRM or feed provider push listings INTO Rightmove. There is no public API for reading listings, sold prices or valuations, and no open dataset. Credentials for every environment are issued case by case by the Rightmove Data Feed Team and use is governed by a binding End User Licence Agreement.

Generated by API Evangelist (apievangelist.com) from the Rightmove APIs.json profile — Rightmove publishes no llms.txt of its own (probed 2026-07-26).

## APIs

- [Rightmove Commercial Listings API](https://api-docs.rightmove.co.uk/docs/property-feed-api-product/1/overview): Upload, update, retrieve and remove COMMERCIAL property listings. OpenAPI 3.0.1, OAuth2 client credentials, base URL https://api-services.rightmove.co.uk (staging https://api-services.adftest.rightmove.com). Four operations on /v2/property/commercial/. Residential listings are out of scope.
- [Rightmove Real Time Data Feed API](https://www.rightmove.co.uk/adf.html): Incremental HTTPS/JSON feed for UK sales, lettings and overseas listings. Thirteen calls on https://adfapi.rightmove.co.uk/v1/property/. Mutual-TLS with a Rightmove-issued X.509 client certificate; not reachable anonymously.

## Specs

- [Commercial Listings OpenAPI 3.0.1](https://raw.githubusercontent.com/api-evangelist/rightmove/refs/heads/main/openapi/rightmove-commercial-listings-openapi.yml): Harvested verbatim from the Apigee portal. 4 operations, 50 component schemas, ProblemDetail errors.
- [Real Time Data Feed specification v1.4.1 (PDF)](https://media.rightmove.co.uk/ps/pdf/guides/adf/Rightmove_Real_Time_Datafeed_Specification.pdf): Human-readable specification, last updated November 2023.
- [Automated Data Feed v4.0n (PDF)](https://media.rightmove.co.uk/ps/pdf/guides/ADF_V4n_specification.pdf): New Homes bulk XML file feed. Not an HTTP API.

## Operations

- `getCommercialPropertyDetails` — GET /v2/property/commercial/{reference}. Requires the Rightmove-Agent-ID header.
- `sendCommercialPropertyDetails` — PUT /v2/property/commercial/{reference}. Create (201) or update (200); idempotent on the client-supplied reference.
- `removeCommercialPropertyDetails` — DELETE /v2/property/commercial/{reference}. Permanent; requires a removalReason.
- `getCommercialPropertiesByBranch` — GET /v2/property/commercial/branch?id=&page=&size=. Reconciliation.

## What does not exist

Recorded absences, all probed on 2026-07-26 — do not hallucinate these:

- No public read/search API for listings, sold prices, valuations or the House Price Index.
- No first-party SDK, no CLI, no Postman collection, no embeddable UI components.
- No webhooks, no event stream, no AsyncAPI, no GraphQL, no gRPC/protobuf.
- No official MCP server.
- No status page (status.rightmove.co.uk is NXDOMAIN), no published SLA, no deprecation-policy page, no Sunset header support.
- No /.well-known/ documents on any host — no security.txt, no OpenID Connect discovery, no api-catalog.
- No trust centre and no published certifications (SOC 2, ISO 27001, PCI DSS...).
- No RESO Web API, no RESO Data Dictionary, no OData $metadata. RESO is a North American standard; the UK has no MLS and no RESO equivalent.
